### Typography
Inter, system-ui fallback. Body 16px/24px regular; heading 20px/28px semibold.

### Spacing, Radius, Elevation
Spacing scale 4/8/16/24px; radius 6px on inputs and cards; no elevation.

## 4. Components
Button (primary, ghost), TextInput (default, error), TaskRow (open, done), EmptyState.

## 5. Accessibility Rules
NFR-A11Y-001: every interactive element keyboard-reachable with a visible focus ring
(`--color-primary`, 2px); all text pairings ≥ 4.5:1.

## 8. Agent Quick Reference
Use tokens only; never a raw hex or px. Done tasks use `--color-muted` text with a strikethrough.
